# STATE (완료 스냅샷)

단계가 끝나면 그 단계를 한 줄로 갱신한다. 세션별 서술은 `HANDOFF.md`에 남긴다.

## 완료된 단계
- 저장소 평탄화 및 `app/` 디렉터리 구조 마이그레이션
- `frontend-reader-web` 프로젝트 식별자 변경 및 AWS 의존성 제거
- 점진적 TypeScript 도입 환경 세팅 (`tsconfig.json`, `npm run typecheck`)
- 시각 에셋 무단 도용 방지(우클릭/드래그 차단) 및 저작권 라이선스 고지
- DPYB 조직 듀얼 백엔드(`backend-core-api`, `backend-ai-agent`) 프록시 개편
- DPYB 바이브 코딩 하네스(`.harness/`, `AGENTS.md`) 및 워크플로우 구성
- DPYB 컨벤션 분할 커밋 및 `develop` 브랜치 최초 원격 푸시 완료
- 월간 독서 리포트 뷰(01~07번 카드 레이아웃), 독서 기록 날씨 조건(`weather`) 전송 및 사서 맞춤형 원클릭 PDF 다운로드 기능 구현
- 개발 단계용 인증 우회 스위치(`VITE_AUTH_BYPASS`) 도입 — dev에서 로그인 무조건 통과
- 사서 특화 장르를 KDC(한국십진분류법) 10대 대분류 체계로 전면 개편, 사서 2종(누디/게코) 임시 추가
- 사서 프로필 페이지에 MBTI·성격·독서 성향·말투 등 페르소나 콘텐츠 보완, 카드 그리드를 4열 고정으로 변경
- 독서 집중 타이머 기능(스톱워치/뽀모도로 모드, 서재 FAB 및 도서 상세 진입) 및 코어 서버 진행률/독서 기록 연동 완료
- 사서 챗봇 내 Core API 기반 내 서재 빠른 조회 모드(상태/장르/저자 자연어 검색 및 원클릭 책 열기) 및 AI 전문 토론자 4인(이동진·설민석·오은영·강형욱 오마주) 선택 UI/백엔드 연동 완료
- AI 사서 독서 토론 모드 내 피날레(종료) 액션 버튼 추가, 백엔드 action: 'conclude' 파라미터 전송 및 맞춤 추천 도서 큐레이션 원클릭 서재 등록 연동 완료
- 사서/페르소나 전환 버튼 명칭 fallback 체인 보강, 챗봇 세로 무한 확장 방지(컨테이너 높이 고정/내부 스크롤 보장) 및 토론 모드 상단 설정 접기/펼치기 아코디언 UX 개선 완료
- 장르 매핑 별칭(aliases) 보강(교양·철학·기술과학) 및 도서 등록 폼 내 세부 장르(subject/displayGenre) 상태 보존과 보조 라벨(예: "기술과학 (컴퓨터/IT)", "교양 (인문교양/상식)") 표시 연동 완료
- 사서 챗봇 높이 컴팩트 복원(상단 사서 프로필 침범 방지), 토론 모드 질문 시작 시 설정 자동 숨김 및 한 줄 배너 내 미니 [🏁 마무리] 버튼 연동, 모드별 세션/답변 격리 완료
- 사서 챗봇 메신저형 멀티턴 대화 히스토리(사용자/어시스턴트 버블 누적 및 자동 스크롤) 구현, 토론 모드 내 서재 카드 억제 및 세션 저장소 연계 완료
- 도움말(?) 아이콘 최상단 헤더 고정 및 모드별 가이드 동적 분기, 날씨·시간대·무드 태그 상단 고정 바 배치(스크롤 밀림 방지 및 추천 모드 전용 노출) 완료
- 모든 동물 사서(블루/슈빌/누디/게코) 커서 말풍선 6초 자동 사라짐 타이머(`useEffect` + `setTimeout`) 및 CSS 페이드인 애니메이션 적용 완료
- 독서 세션 저장 API(`POST /books/{id}/reading-sessions` 및 `/records` 폴백) 연동, 도서 상세 내 문장수집과 분리된 독서 타이머 전용 세션 테이블(`ReadingSessionHistory`) UI 구축 완료
- 독서 진행률 1% 이상(1쪽 이상) 도서의 '시작전' 상태 불일치 버그 해결: `toKoreanStatus` 자동 승격 보정 및 타이머/페이지 저장 시 백엔드 `READING`(읽는 중) 메타데이터 동기화 완료
